# CareBridge Phase 1 Marketplace

A Next.js 15 marketplace UI for CareBridge with no public prices.

## Included
- Category-first homepage
- Medicines
- Medical equipment purchase and rental
- Daily pooja essentials
- Festival care boxes
- Coming-soon services
- WhatsApp-assisted ordering

## Run
```bash
npm install
npm run dev
```

## Deploy
Upload all files and folders in this directory to the root of the GitHub repository, then deploy the repository on Vercel.
